# 🎤 말로 하는 끝말잇기

아이들을 위한 음성 끝말잇기 웹 앱입니다. 마이크에 대고 단어를 말하면 컴퓨터가 알아듣고, 목소리로 대답해요!

## ✨ 기능

- **🎙️ 음성 인식** — 마이크 버튼을 누르고 단어를 말하면 자동으로 인식 (Web Speech API)
- **🔊 음성 합성** — 컴퓨터가 자기 단어를 직접 말해 줘요
- **📖 두음법칙 지원** — `력→역`, `라→나` 등 자동 처리 (예: "실력" 다음에 "역기" 가능)
- **🐣 난이도 3단계** — 쉬움(이어가기 쉬운 단어), 보통, 어려움(어려운 단어로 공격!)
- **💡 힌트 / 🙈 몰라요** — 막히면 힌트를 듣거나 항복할 수 있어요
- **⏰ 시간 제한** — 없음 / 10초 / 20초 / 30초 선택
- **🏆 점수 기록** — 승패가 브라우저에 저장돼요
- **⌨️ 키보드 입력** — 음성 인식이 안 되는 브라우저를 위한 대체 입력
- **🎉 축하 효과** — 이기면 색종이가 날려요!

## 🚀 실행 방법

음성 인식은 **크롬(Chrome) 또는 엣지(Edge)** 브라우저에서만 동작하며, `localhost` 또는 `https` 환경이 필요합니다.

```bash
# 저장소 폴더에서 간단한 웹 서버 실행
python3 -m http.server 8000
```

그다음 크롬에서 **http://localhost:8000** 을 열고, 마이크 사용을 **허용**해 주세요.

> 📱 휴대폰에서는 안드로이드 크롬을 추천합니다. (iOS 사파리는 음성 인식 미지원 — 키보드 입력으로 플레이 가능)

## 🎮 게임 규칙

1. 서로 번갈아 가며 앞 단어의 **끝 글자로 시작하는 단어**를 말해요.
2. 두 글자 이상만 인정, 이미 나온 단어는 다시 쓸 수 없어요.
3. 이어갈 단어를 말하지 못하면 상대가 이겨요.
4. 기본 설정은 아이가 아는 단어를 자유롭게 인정하는 **너그러운 모드**예요. "사전에 있는 단어만 인정"을 켜면 내장 사전(약 470단어)에 있는 단어만 인정합니다.

## 🗂️ 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 알록달록 스타일 |
| `app.js` | 게임 로직 + 음성 인식/합성 |
| `words.js` | 컴퓨터가 아는 단어 사전 (약 470개, 아이 눈높이 단어) |

단어를 더 가르치고 싶으면 `words.js`의 배열에 단어를 추가하면 됩니다!
